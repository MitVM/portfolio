CVE-2026-46300
Fragnesia
Critique Patches disponibles
7.8
Score CVSS v3.1
Fragnesia est une vulnérabilité d'élévation de privilèges locale dans le sous-système XFRM ESP-in-TCP du noyau Linux. Elle permet à un attaquant local non privilégié d'écrire des octets arbitraires dans le cache de pages de fichiers en lecture seule (comme /usr/bin/su), sans nécessiter de race condition, et d'obtenir un shell root.

La faille exploite un défaut logique dans le mécanisme SKBFL_SHARED_FRAG : lors de la fusion de socket buffers (skb), le noyau peut traiter des pages file-backed en file d'attente comme du texte chiffré ESP et les déchiffrer en place — créant une primitive d'écriture déterministe d'un octet sur le cache de pages.

CVE-2026-1281 & CVE-2026-1340
Ivanti EPMM RCE
Critique Exploitée activement
9.8
Score CVSS v3.1
Double vulnérabilité critique dans Ivanti Endpoint Manager Mobile (EPMM), anciennement MobileIron. Ces failles permettent à un attaquant non authentifié de provoquer une exécution de code arbitraire à distance (RCE) sur les serveurs affectés.

Le CERT-FR a émis une alerte (CERTFR-2026-ALE-001) le 30 janvier 2026, signalant leur exploitation active dans le cadre d'attaques ciblées. Une preuve de concept est disponible publiquement. Les organisations utilisant EPMM doivent appliquer les correctifs Ivanti immédiatement — tout serveur exposé depuis le 28 janvier 2026 sans correctif doit être considéré comme potentiellement compromis.

CVE-2025-53521
F5 BIG-IP APM — RCE
Critique Exploitation confirmée mars 2026
9.8
Score CVSS v3.1
Vulnérabilité critique dans F5 BIG-IP APM (Access Policy Manager) permettant à un attaquant non authentifié d'exécuter du code à distance sur les équipements affectés. Publiée initialement en octobre 2025, son exploitation active a été confirmée par le CERT-FR en mars 2026 (CERTFR-2026-ALE-004).

Les équipements F5 BIG-IP sont très répandus dans les grandes infrastructures (load balancing, VPN, gestion d'accès) — leur compromission peut donner un accès privilégié à l'ensemble du trafic réseau d'une organisation. Cette faille illustre l'importance d'une veille continue même sur les équipements réseau critiques.

CVE-2026-42897
Microsoft Exchange Server
Élevée Patchée — juin 2026
8.1
Score CVSS v3.1
Vulnérabilité dans Microsoft Exchange Server permettant à un attaquant non authentifié de provoquer une exécution de code à distance. Divulguée initialement le 14 mai 2026, Microsoft a publié les versions correctives le 9 juin 2026, dans le cadre du Patch Tuesday.

Exchange Server est l'une des cibles les plus convoitées par les attaquants — un serveur de messagerie compromis donne accès aux emails de toute l'organisation, aux contacts, aux calendriers et peut servir de point de pivot vers le reste du réseau interne. Le CERT-FR a mis à jour son alerte le 11 juin 2026 pour confirmer la disponibilité du correctif.

CVE-2026-32312 et al.
GLPI — 7 vulnérabilités
Haute Corrigée dans GLPI 10.0.25+
8.3
Score CVSS max
Sept vulnérabilités documentées par le CERT-FR (CERTFR-2026-AVI-0551) affectant GLPI, la solution open-source de gestion de parc informatique très utilisée dans les collectivités et administrations françaises. Les risques identifiés comprennent : SSRF (falsification de requêtes côté serveur), XSS (injection de code indirect), RCE (exécution de code à distance), et SQLi (injection SQL).

Ce cas est particulièrement pertinent dans mon contexte professionnel chez SNA27 où GLPI est utilisé quotidiennement pour la gestion du parc et des tickets. Les données sensibles qu'il contient (inventaire, incidents, données des agents) en font une cible de choix. Les versions antérieures à 10.0.25 et 11.0.7 sont vulnérables.
